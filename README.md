# AI-Assisted Radiology Report Generator

A multimodal healthcare AI prototype built using Google ADK and Gemini 2.5 Flash.

## Features

- Medical image upload
- AI-generated radiology reports
- Structured findings and impressions
- PDF report generation
- Google ADK workflow orchestration

## Tech Stack

- Google ADK
- Gemini 2.5 Flash
- Python
- FPDF

## Workflow

Medical Scan Upload → Gemini Vision → ADK Agent → Structured Report → PDF Generation

## Setup

```bash
pip install -r requirements.txt
adk web
